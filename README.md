# Workshop Spring Boot

Projeto desenvolvido durante meus estudos de **Java e Spring Boot**, baseado no curso do **Nelio Alves**.

O projeto teve como objetivo consolidar conceitos fundamentais do desenvolvimento backend com Spring Boot, desde a construção de uma API REST até a persistência de dados utilizando JPA/Hibernate e MySQL.

## 🎯 Objetivos

- Consolidar conhecimentos de Programação Orientada a Objetos com Java
- Aprender a estrutura e funcionamento do Spring Boot
- Compreender a arquitetura em camadas
- Desenvolver uma API RESTful
- Implementar operações CRUD
- Trabalhar com persistência de dados utilizando JPA/Hibernate
- Modelar associações entre entidades
- Integrar a aplicação com um banco de dados MySQL

## 🛠️ Tecnologias utilizadas

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **JPA / Hibernate**
- **MySQL**
- **Maven**
- **Postman**
